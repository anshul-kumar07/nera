# SIH NER Logistics

This repository contains the NER Logistics / SIH project for emergency logistics, route intelligence, incident monitoring, and operations coordination.

## Project structure

- `ner-logistics/` – main Next.js application
- `competitive_advantage.md` – product and strategic notes
- `live_map_features.md` – live map feature documentation
- `phase1_development.md` – development plan
- `SIH_guide.md` – project guidance
- `SIH.txt` – project notes

## Getting started

```bash
cd ner-logistics
npm install
npm run dev
```

Then open http://localhost:3000 in the browser.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
