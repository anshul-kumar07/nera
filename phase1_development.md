## Live Pages in App

1. **`/`** — High-impact landing page highlighting NER logistics challenges and system capabilities.
2. **`/dashboard`** — Central command dashboard with live Supabase metrics and the **AI 48-Hour Disruption Prediction Engine**.
3. **`/map`** — Interactive GIS map with color-coded highway statuses and the **AI Alternate Route Suggestion Engine**.
4. **`/vehicles`** — Fleet monitoring table with driver details, cargo classification (medicines, food, fuel, construction), and status indicators.
5. **`/incidents`** — Live field incident registry with GPS coordinates, timestamps, and severity classifications.
6. **`/report`** — Field official report submission with GPS auto-capture and **instant multilingual alert generation (English, Hindi, Assamese)**.
7. **`/analytics`** — District connectivity charts, cargo breakdown pie chart, and incident heat stats.
